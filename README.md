Unemployment Analysis During Covid-19 Using Python

Project Overview

This project analyzes the unemployment rate in India during the Covid-19 pandemic using Python.
The project focuses on data cleaning, exploratory data analysis (EDA), and visualization of unemployment trends across different states and regions.

The Covid-19 pandemic caused a major impact on employment, making unemployment analysis an important real-world data science project.

Objectives
Analyze unemployment trends during Covid-19
Compare unemployment rates across states
Visualize unemployment growth during lockdown periods
Understand labour participation patterns
Perform data cleaning and exploratory data analysis

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

## Dataset
- Unemployment in India.csv
- Unemployment_Rate_upto_11_2020.csv

## Steps
1. Import libraries
2. Load dataset
3. Clean data
4. Analyze unemployment rates
5. Create visualizations
6. Study Covid-19 impact

## Features
- State-wise unemployment analysis
- Covid-19 unemployment trends
- Graphs and charts
- Data visualization

## Output
The project shows how unemployment increased during the Covid-19 pandemic.
